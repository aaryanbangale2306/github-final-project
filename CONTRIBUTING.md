# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes (`git checkout -b feature/improvement`).
3. Make your changes and test thoroughly.
4. Commit your changes with a clear and descriptive commit message.
5. Push your branch to GitHub (`git push origin feature/improvement`).
6. Create a Pull Request with an explanation of your modifications.

## Contribution Guidelines

Please ensure your contributions are relevant to the project and maintain clear, readable, and well-documented code. Follow standard Git branching and commit practices.

Thank you for contributing to the Simple Interest Calculator project!
